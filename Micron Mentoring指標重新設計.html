Design Principles

設計原則

本次重新設計聚焦於四個面向：填答者角色清楚劃分、指標的可觀察性、評估時程與 program 階段的搭配、與既有資料系統的分工。以下五項原則回應這些面向。

01
填答者角色清楚劃分
每項指標交由具備該題項觀察角度的角色填答，確保資料來源具備直接證據基礎。
02
短期問過程，長期問成果
季度檢視互動是否實際發生，年度才評估行為改變與實質產出。
03
既有系統有資料就不重問
論文、專利、留任率、360 回饋等資料如果能在既有系統中追蹤，應直接調用，避免請 mentor 重複評估。
04
跨 program 留共同題
配對品質與整體滿意度等基礎題項各 program 共用，以維持彙整時的可比性。
05
敏感議題一律匿名
Pride+ Allies 與 MWLN 涉及身份議題，mentee 端題項採匿名蒐集，以獲得相對真實回饋。
Rating Sources

三類評估來源

每個指標標明填答者來源，由具備第一手觀察角度的角色負責該題項。

Mentee
學員 / 受指導者
負責自身學習收穫、行為改變與感受面向的回饋，包含學習內容吸收度、信心變化、滿意度等僅本人可判斷的題項。
Mentor
導師
負責學員在 mentoring 場域中可被觀察的表現，包含學員準備程度、提問深度、討論進展等互動現象。
Owner
Program 負責人
負責 program 整體的執行狀況與群體現象，例如出席率、配對留存、資源配置情形，不評估個別 mentee 的主觀感受。
Cross-Program Core

跨 Program 共用核心指標

以下題項在所有 program 共用，做法、量表與時點統一，以維持跨 program 彙整時的比較基準。

Short Term
短期共用指標
PER QUARTER
  • 配對關係建立度（與 mentor 關係建立程度） Mentee
  • 互動頻率達成率（實際 ÷ 預期次數） Mentee
  • Mentor 投入感知（感受到 mentor 投入時間與心力） Mentee
  • 互動頻率達成率（mentor 端紀錄） Mentor
  • Mentee 投入感知（感受到 mentee 主動參與與準備） Mentor
  • Program 整體執行順暢度（行政、資源、媒合） Owner
Long Term
長期共用指標
PER YEAR
  • 整體 mentoring 滿意度 Mentee
  • Mentor 推薦意願（推薦他人加入 program） Mentee
  • Mentor 持續意願（下一期是否續任） Mentor
  • 配對留存率（完成完整週期的配對比例） Owner
  • Program ROI 感知（投入資源 vs. 產出效益） Owner

長期指標 YEARLY

表達自身需求能力的改變 Mentee

對美光雇主品牌的好感度 Mentee

調整說明 原指標中整體穩定度提升與職場適應信心兩題語意相近，本次合併並改由 mentee 自評。心理狀態屬於 mentee 第一手感受，由本人填答可提升資料效度。
